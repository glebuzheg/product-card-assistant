# Design

## Context
На main проходил 51 тест. Производственные модули — api.py, generation.py и schemas.py.

## Goals / Non-Goals
Проверить силу тестов без изменения продукта. Не добиваться формальных 100% через тесты точного текста ошибок или исключение трудных мутаций.

## Decisions
mutmut 3.8.1, все функции product_cards/, четыре процесса, forkserver. Копировать только tests и публичные examples; секреты не копировать. Сохранить исходную статистику до добавления тестов, затем повторить прогон.

## Risks / Trade-offs
Инструмент не мутирует декларации Pydantic и прочий код вне функций; это явно отметить в отчёте. Таймауты не считать автоматически обнаруженными ошибками без проверки. Эквивалентные и косметические мутации разобрать отдельно.
