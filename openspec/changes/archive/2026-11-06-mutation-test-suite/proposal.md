# Proposal

## Why
Проверить, обнаруживает ли существующий набор тестов реальные ошибки при небольших изменениях приложения.

## What Changes
- Настройка mutmut и воспроизводимый локальный прогон.
- Тесты для существенных выживших мутаций.
- Отчёт с исходным и повторным результатом, разбором выживших и ограничениями инструмента.

## Capabilities

### New Capabilities
Нет: изменение тестов и инструментов не меняет контракт продукта; skip_specs=true.

### Modified Capabilities
Нет.

## Impact
Зависимости разработки, pyproject.toml, .gitignore, tests/ и документация. Платные API не вызываются; mutmut работает в mutants/, куда .env не копируется.
