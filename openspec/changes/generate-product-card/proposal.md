# Proposal

## Why
Контент-менеджеру нужен проверяемый черновик карточки прибора по исходным фактам, без ручного составления SEO-текста и выдуманных характеристик.

## What Changes
- Локальный JSON API генерации карточки через OpenAI.
- Проверка входа, длин, источников технических утверждений и ошибок API.
- Два реальных входных примера, документация и автоматические тесты.
- Без БД, CMS, отдельного frontend и деплоя.

## Capabilities

### New Capabilities
- `product-card-generation`: генерация и проверка черновиков, неполные данные, ошибки провайдера.

### Modified Capabilities
Нет.

## Impact
Новый Python-проект: FastAPI, Pydantic, OpenAI SDK; pytest, Ruff и uv для разработки. Данные публичных товаров передаются в OpenAI, секреты остаются в окружении.
