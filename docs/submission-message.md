Реализовал локальный сервис на Python и FastAPI: он принимает JSON с данными прибора и возвращает черновик карточки с SEO-текстом, характеристиками, поисковыми запросами и блоком для менеджера.

Для генерации использовал OpenAI gpt-4.1 со Structured Outputs, для проверки — Pydantic, точные цитаты источников и контроль числовых значений. Характеристики переносит код; недостаток данных и ошибки API обрабатываются явно. Требования и выполненные задачи оформлены в OpenSpec, инструкции запуска и ограничения — в README.

Основная сложность — добиться корректного цитирования и избежать неподтверждённых выводов модели. Добавил ограничение путей источников, одну корректирующую попытку с предыдущим ответом и ручную сверку двух реальных примеров — testo 510 и testo 105. Автоматические тесты и проверки GitHub Actions проходят; результат остаётся черновиком для проверки контент-менеджером.
