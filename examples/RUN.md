Оба результата получены настоящими вызовами API, каждый после одной автоматической корректировки. Сохранённые выходы совпадают с ответами API после сборки таблицы характеристик кодом; тексты вручную не переписывались. Проверены длины, цитаты и числовые значения. При ручной сверке сопоставлены диапазоны, условия погрешности, питание, классы IP, принадлежности и области применения с входными JSON. Новых технических характеристик в выбранных примерах не обнаружено. Условие применения трубки Пито в карточке манометра сохранено, сменные наконечники не объявлены частью комплекта термометра.

При подготовке пробовали `gpt-4.1-mini`: несколько ответов были отклонены из-за неверных цитат, оборванного заголовка или неподтверждённых формулировок при ручной сверке. Для финальных примеров и настройки проекта выбрана `gpt-4.1`. Это выбор по двум примерам, а не полноценный сравнительный benchmark моделей.

Во время реального прогона уточнили проверку путей источников (enum), добавили предыдущий ответ в исправляющий запрос и отклонение явно оборванных заголовков. Строгая проверка цитат сохранена.

Ранее API возвращал `credit_balance_exhausted`; после пополнения API-баланса проблема решена. Ключ и `.env` не включены в Git. В API передавались только публичные сведения выбранных товаров.

Результаты остаются черновиками: проверка на двух товарах не гарантирует достоверности произвольной будущей генерации. Перед публикацией нужна проверка специалистом.
